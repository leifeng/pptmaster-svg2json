# svg-to-pptel

SVG to PPTElement JSON converter.

## 安装

```bash
npm install
```

## 构建

```bash
npm run build
```

## 运行

```bash
npx svg2json <input.svg> -o <output.json>
```

## Linux/macOS

```bash
chmod +x ./node_modules/.bin/svg2json
./node_modules/.bin/svg2json <input.svg> -o <output.json>
```
