# Quick Task: 所有常量放到单独文件

## 目标

把 src/ 下散落的命名常量统一提取到 `src/constants.ts`，便于集中维护和查阅。

## 迁移清单

|------|------|------|------|
| `src/utils/logger.ts:6` | `PREFIX` | `LOG_PREFIX` | 重命名以明确语义 |
| `src/preprocessor/font-preprocessor.ts:6` | `TARGET_FONT` | `TARGET_FONT` | 名称不变 |
| `src/text-measurer.ts:14` | `FONT_FILE` | `FONT_FILE` | 名称不变 |
| `src/text-measurer.ts:19` | `FONT_OPTIONS` | `FONT_OPTIONS` | 名称不变 |

| `src/transformer/transform-to-pptel.ts:126` | `namedColors` | `NAMED_COLORS` | 重命名为大写以统一风格 |

## 实施步骤

### 1. 创建 `src/constants.ts`

按业务领域分组（注释分割）：

```typescript
// 1. 日志前缀 (LOG_PREFIX)
// 2. 字体相关 (TARGET_FONT, FONT_FILE, FONT_OPTIONS)
// 3. 文本测量/转换 (TEXT_WIDTH_SAFETY_MARGIN, FALLBACK_ASCENT_RATIO, TEXT_ANCHOR_MIDDLE_TOP_OFFSET)
// 4. 命名颜色 (NAMED_COLORS)
// 5. SVG <use> 标签 (ICONS_BASE, STYLE_CONFIG)
```

### 2. 更新各源文件

每个文件：
1. 删除原常量定义
2. 在文件顶部添加 `import { ... } from '../constants'` (或 './constants')
3. 替换所有内部引用

### 3. 验证

- `npx tsc --noEmit` 通过
- 现有测试全部通过
- `__tests__/text-anchor.test.ts` 7/7 通过（确保 TEXT_ANCHOR_MIDDLE_TOP_OFFSET 行为不变）

## 路径兼容性

`FONT_FILE` 和 `ICONS_BASE` 使用 `__dirname`。两者目标文件都编译到 `dist/src/`，所以 `__dirname` 都是 `dist/src/`。路径结果不变。

## 不在迁移范围

- 函数内部的 magic numbers（如 `[1000, 562.5]` 默认画布尺寸）—— 是参数默认值而非命名常量
- `as const` 类型断言（如 `['fill', 'stroke', ...] as const`）—— 是类型工具
- 测试 fixture 中的常量
- `dist/` 中已编译产物

## 风险

- **import 路径**：每个源文件需要添加 `from './constants'` 或 `'../constants'`，取决于目录深度
- **名称变化**：`PREFIX → LOG_PREFIX`、`namedColors → NAMED_COLORS`，需要全局搜索替换
- **默认导出 vs 命名导出**：全部使用命名导出，与原代码风格一致
