# Requirements: svg-to-pptel

**Defined:** 2026-10-19
**Core Value:** 准确把 SVG 元素转换为 PowerPoint JSON — 坐标、变换、样式映射正确，附带语义层 annotation（animations / template markers / content slots / pageData）。

## v1.14 Requirements

### Dependencies

- [x] **NU-01**: `src/utils/id-generator.ts` 移除 `nanoid/non-secure` import,改用 `uuid` 包导出 — 实际调用 `uuidv4()`(已通过 `transformElement()` 入口 fallback 验证可用)
