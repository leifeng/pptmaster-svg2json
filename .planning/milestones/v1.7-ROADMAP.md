# Milestone v1.7: Path 合并优化

**Status:** ✅ SHIPPED 2026-07-23
**Phases:** 10-12
**Total Plans:** 5

## Overview

v1.7 聚焦于路径合并优化、文本测量优化和字体预处理。主要成果包括实现 `<g>` 内全 `<path>` 子元素的合并决策逻辑、SVG text 属性直通以跳过不必要的 resvg-js 测量、以及统一字体为 Source Han Sans CN Regular。

## Phases

### Phase 10: Path Merge — 决策树与合并引擎

**Goal:** 实现 `<g>` 内全 `<path>` 子元素的合并决策逻辑，减少输出元素数量
**Depends on:** —
**Plans:** 2 plans

Plans:

- [x] 10-01: Create path-merge module with decision tree
- [x] 10-02: Add unit tests for path-merge

**Details:**
- 创建 `src/merger/path-merge.ts` 模块，包含 `shouldMerge/mergePaths` 决策树
- 扩展 `pathBoundingBox()` 支持 C/Q/S/T 曲线命令
- 集成到 `walk()` 实现全 path 组检测
- 27 个单元测试覆盖

### Phase 11: Text Width/Height Passthrough — SVG text 属性直通

**Goal:** SVG `<text>` 同时声明 `width` 和 `height` 时，跳过 resvg-js 测量，直接使用属性值
**Depends on:** Phase 10
**Plans:** 1 plan

Plans:

- [x] 11-01: Text width/height passthrough implementation

**Details:**
- 实现 `<text width="..." height="...">` 直通快速路径
- 缩放后 `width = parsedWidth * scaleX + TEXT_WIDTH_SAFETY_MARGIN`、`height = parsedHeight * scaleY`
- 字体加载修复：思源黑体加载让 Resvg 测量与 PPTist 渲染一致

### Phase 12: Font Preprocess — 统一字体

**Goal:** 在 SVG 被解析转换之前，将文件中所有字体替换为 "Source Han Sans CN Regular"
**Depends on:** Phase 11
**Plans:** 1 plan

Plans:

- [x] 12-01: Font preprocessor implementation

**Details:**
- 创建 `src/preprocessor/font-preprocessor.ts`
- `normalizeFontFamily()` 函数替换所有字体
- 14 个测试用例全部通过
- 集成到 `convert()` 函数
