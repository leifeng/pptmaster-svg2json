## Phases

### Phase 10: Path Merge — 决策树与合并引擎

**Goal**: 实现 `<g>` 内全 `<path>` 子元素的合并决策逻辑，减少输出元素数量
**Depends on**: None
**Plans**: 2 plans

Plans:

- [x] 10-01: Create path-merge module with decision tree (shouldMerge/mergePaths) and extend pathBoundingBox for C/Q/S/T curves
- [x] 10-02: Add comprehensive unit tests for path-merge module

**Details:**
Phase 10 implements the path merge feature with a decision tree that determines whether to merge multiple `<path>` elements within a `<g>` group based on:
1. Shared style attributes (fill, stroke, opacity, fill-rule)
2. Independent semantic needs (id, aria-*, event bindings)
3. fill="none" detection or bounding box overlap
4. fill-rule="evenodd" special handling
