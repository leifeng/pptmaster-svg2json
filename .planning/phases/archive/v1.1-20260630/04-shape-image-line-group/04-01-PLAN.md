Implement SHPE-01 (rounded rect corners) and LINE-01 (stroke-width to width mapping). These are independent, straightforward field mappings that can be developed in parallel with Wave 1 shadow/groupId work.
</objective>

## Phase Goal (User Story)

**As a** designer **I want** SVG rounded rectangles and lines to preserve their styling when converting to PPTist format **so that** rounded corner shapes and lines with custom stroke width render correctly in my slides.

## Locked Decisions

- **D-21:** `rx`/`ry` → SVG arc commands in path. sweep-flag = 1 (clockwise). When rx=0 or ry=0 → sharp corners. When rx/ry exceed half-width/half-height → clamp to min(width,height)/2.
- **D-24:** SVG `stroke-width` → PPTLineElement.width. Default to 1 when absent or 0.

  <action>
    Add roundedRectToPath function to src/shapes/shape-to-path.ts:

    Per D-21: Generate rounded rectangle path using arc commands at each corner.
    sweep-flag = 1 (clockwise). When rx=0 or ry=0 → degenerate to sharp corners.
    When rx/ry exceed half-width/half-height → clamp to min(width, height)/2.

    Arc command format: `A rx ry x-axis-rotation large-arc-flag sweep-flag x y`

    For a rect at origin (0,0) with width w and height h and corner radius r:
    - Top-left corner: start at (r, 0), arc to (0, r)
    - Bottom-left: start at (0, h-r), arc to (r, h)
    - Bottom-right: start at (w-r, h), arc to (w, h-r)
    - Top-right: start at (w, r), arc to (w-r, 0)

    Path sequence:
    ```
    M r,0
    L w-r,0
    A r,r 0 0,1 w,r
    L w,h-r
    A r,r 0 0,1 w-r,h
    L r,h
    A r,r 0 0,1 0,h-r
    L 0,r
    A r,r 0 0,1 r,0
    Z
    ```

    When r=0, use simple `L w,0 L w,h L 0,h L 0,0 Z` (sharp corners).
  </action>
