# Plan: font-preprocess

## 目标

在 SVG 被解析转换之前，将文件中所有字体替换为 "Source Han Sans CN Regular"，确保输出 PowerPoint 的一致性。

## 当前行为

- SVG 中的字体属性（`font-family`、`font` 等）直接透传到输出
- `<text>` 元素可能使用任意字体，导致 PowerPoint 呈现不一致
- CSS `<style>` 标签内的字体声明也不会被处理

## 目标行为

- 转换前预处理 SVG 字符串，将所有字体替换为 "Source Han Sans CN Regular"
- 处理属性级别的字体：`font-family`、`font-size`、`font-weight`、`font-style`
- 处理 CSS 样式中的字体声明
- 不修改 SVG 的其他内容

## 实现步骤

### 1. 创建字体预处理模块 — `src/preprocessor/font-preprocessor.ts`

新建文件，实现 `normalizeFontFamily(svgContent: string): string` 函数：

**处理属性级别的字体：**
- `font-family="xxx"` → `font-family="Source Han Sans CN Regular"`
- `font="xxx"` → `font="Source Han Sans CN Regular"`
- `font-size="xxx"` → 保持不变（仅替换字体家族）
- `font-weight="xxx"` → 保持不变
- `font-style="xxx"` → 保持不变

**处理 CSS `<style>` 标签内的字体声明：**

需要处理以下 CSS 属性：
- `font-family`
- `font`（ shorthand）
- 所有以 `font-` 开头的属性

```typescript
export function normalizeFontFamily(svgContent: string): string {
  let result = svgContent

  // 1. 替换属性中的 font-family
  result = result.replace(
    /font-family\s*=\s*["']([^"']*)["']/gi,
    'font-family="Source Han Sans CN Regular"'
  )

  // 2. 替换属性中的 font（shorthand，包含 font-family）
  result = result.replace(
    /font\s*=\s*["']([^"']*)["']/gi,
    (match, fontValue) => {
      // 替换 font-value 中的 font-family 部分
      const normalized = fontValue.replace(
        /\bfamily\s*\/\s*[^\s]+/gi,
        'family/Source Han Sans CN Regular'
      ).replace(
        /\bfont-family\s+[^\s;]+/gi,
        'font-family Source Han Sans CN Regular'
      )
      // 如果没有 family，使用 font-size/line-height font-family 格式
      if (!/family/i.test(normalized)) {
        const parts = normalized.split(/\s+/)
        // 查找 font-size/line-height 位置，插入 family
        const newParts: string[] = []
        let foundSize = false
        for (const part of parts) {
          if (/^\d+(\.\d+)?(px|pt|em|%)?$/i.test(part)) {
            if (!foundSize) {
              newParts.push(part) // font-size
              newParts.push('Source Han Sans CN Regular') // 插入 family
              foundSize = true
            } else {
              newParts.push(part) // line-height
            }
          } else {
            newParts.push(part)
          }
        }
        return `font="${newParts.join(' ')}"`
      }
      return `font="${normalized}"`
    }
  )

  // 3. 处理 <style> 标签内的 CSS 规则
  result = result.replace(
    /(<style[^>]*>)([\s\S]*?)(<\/style>)/gi,
    (match, openTag, cssContent, closeTag) => {
      const normalizedCss = cssContent
        // font-family 声明
        .replace(/font-family\s*:\s*[^;]+;/gi, 'font-family: Source Han Sans CN Regular;')
        // font shorthand 中包含 family 的情况
        .replace(/font\s*:\s*([^;]+);/gi, (m, fontDecl) => {
          // 简单处理：确保有 family
          if (/family/i.test(fontDecl)) {
            return `font: ${fontDecl.replace(/family\s*\:\s*[^;]+/i, 'family: Source Han Sans CN Regular')};`
          }
          return m
        })
        // 其他 font-* 属性保持不变
      return openTag + normalizedCss + closeTag
    }
  )

  return result
}
```

### 3. 添加单元测试 — `src/preprocessor/font-preprocessor.test.ts`

测试用例：

```typescript
describe('normalizeFontFamily', () => {
  it('替换 font-family 属性', () => {
    const svg = '<text font-family="Arial">Hello</text>'
    const result = normalizeFontFamily(svg)
    expect(result).toContain('font-family="Source Han Sans CN Regular"')
  })

  it('替换 font 属性中的 family', () => {
    const svg = '<text font="12px/1.5 Arial">Hello</text>'
    const result = normalizeFontFamily(svg)
    expect(result).toContain('Source Han Sans CN Regular')
  })

  it('替换 <style> 中的 font-family CSS 声明', () => {
    const svg = `<style>.text { font-family: Arial; }</style>`
    const result = normalizeFontFamily(svg)
    expect(result).toContain('font-family: Source Han Sans CN Regular;')
  })

  it('不影响非字体属性', () => {
    const svg = '<text font-size="14" fill="#000">Hello</text>'
    const result = normalizeFontFamily(svg)
    expect(result).toContain('font-size="14"')
    expect(result).toContain('fill="#000"')
  })

  it('处理嵌套的 <tspan> 元素', () => {
    const svg = '<text><tspan font-family="Arial">Inner</tspan></text>'
    const result = normalizeFontFamily(svg)
    expect(result).toContain('Source Han Sans CN Regular')
  })
})
```

## 验收标准

1. `normalizeFontFamily` 函数存在且导出
2. 属性 `font-family="xxx"` 被替换为 `font-family="Source Han Sans CN Regular"`
3. CSS `<style>` 标签内的 `font-family: xxx;` 被替换
4. 非字体属性（`font-size`、`fill` 等）保持不变
5. 现有测试全部通过

## 风险

- CSS `font` shorthand 格式复杂，简单正则可能无法覆盖所有变体
- 需要处理引号有无、单引号双引号等边界情况
