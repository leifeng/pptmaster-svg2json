    1. Run `npm install @resvg/resvg-js` to install the package (MEAS-01).

    2. Create `src/text-measurer.ts` with the following exports:
       - `buildMeasurementSvg(opts: { content: string, fontFamily: string, fontSize: number, fontWeight?: string, fontStyle?: string, letterSpacing?: number, fill?: string }): string` — constructs a self-contained SVG with xml:space="preserve", fixed viewBox "0 0 1280 720" per D-37, width/height="1280"/"720", text at x="0" y="fontSize", escaping & < > " for XML safety. Font attributes default: fontWeight="normal", fontStyle="normal", letterSpacing=0, fill="#000000".
       - `measureTextBBox(svgString: string): Promise<{ width: number, height: number }>` — lazy singleton async init, renders via resvg-js, merges all boundingBoxes() entries via min/max computation, throws if boxes array is empty or all-zero.
       - `measureTextElement(input: TextMeasurementInput): Promise<{ width: number, height: number }>` — calls buildMeasurementSvg then measureTextBBox, catches any error and re-throws so caller can fallback.
       - `TextMeasurementInput` interface with fields: content, fontFamily, fontSize, fontWeight?, fontStyle?, letterSpacing?, fill?.

    3. Create `src/text-measurer.test.ts` with vitest tests covering:
       - `buildMeasurementSvg` produces valid SVG with correct viewBox and escaped content
       - `measureTextBBox` returns {width, height} for simple text (e.g. "Hello")
       - `measureTextBBox` returns merged bbox for multi-line text (content with \n)
       - Empty content throws (triggers fallback path)
       - Boxes with zero dimensions throw
       - Font attributes (family, size, weight, style, letter-spacing) are reflected in the SVG output
  </action>
