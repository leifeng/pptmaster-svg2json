<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI 启动 → 本地字体文件 | 本地构建产物和字体路径是运行时输入，文件可能缺失、不可读或被替换。 |
| CLI 启动 → Resvg native runtime | 字体文件通过 `FONT_OPTIONS` 进入 resvg-js native 加载路径，构造失败必须被显式处理。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-01 | Tampering | `FONT_FILE` / Resvg font loading | medium | mitigate | 在 CLI 处理文件前检查目标文件存在，并同步构造 `Resvg`；失败立即返回非零退出，阻止使用未验证的 fallback 字体。 |
| T-13-02 | Information Disclosure | CLI error output | low | accept | 错误需显示绝对路径以便修复，路径只指向本地构建字体资源，不输出文件内容或凭据。 |
| T-13-SC | Tampering | npm/build artifact installation | high | mitigate | 本阶段不新增或安装 npm 包；执行阶段通过现有构建和测试验证字体复制产物，保留依赖安装完整性检查。 |
</threat_model>
