## Locked Decisions

- **D-18:** SVG `fill-opacity` → rgba() color string (consistent with D-08 text fill-opacity)
- **D-19:** SVG `stroke-opacity` → PPTist `outline.opacity` field
- **D-20:** SVG element `opacity` → PPTElement `opacity` field

## Implementation Notes

**D-19 clarification:** PPTElementOutline (slides.ts:86-90) has no opacity field currently:
```typescript
export interface PPTElementOutline {
  style?: LineStyleType
  width?: number
  color?: string
}
```

The decision says stroke-opacity should map to `outline.opacity`. This requires extending PPTElementOutline to add an opacity field, OR using a different interpretation.

**D-19 interpretation:** Looking at PPTist schema, outline.opacity likely means the opacity of the outline itself. The SVG stroke-opacity affects the stroke alpha. We should add `opacity?: number` to PPTElementOutline interface.

**D-20:** PPTShapeElement already has `opacity?: number` at line 384. This is straightforward.
