## Phase Goal

**As a** SVG parser, **I want to** parse transform attributes (translate/rotate/scale) and map them to PPTist's rotate/flipH/flipV fields, **so that** transformed SVG elements render correctly in PPTist.

    Create src/transformer/apply-transform.ts with the following exports:

    1. applyRotateWithCenter(x, y, deg, cx, cy): {x, y}
       - Per D-01: translate->rotate->translate-back formula
       - Formula: px=x-cx, py=y-cy; rx=px*cos(θ)-py*sin(θ); ry=px*sin(θ)+py*cos(θ); final_x=rx+cx, final_y=ry+cy
       - θ = deg * Math.PI / 180

    2. getRotateDeg(transform: TransformResult): number
       - Per D-02: returns transform.rotateDeg || 0

    3. getFlipFromScale(transform: TransformResult): {flipH?: boolean, flipV?: boolean}
       - Per D-03: if transform.scaleX < 0, flipH = true
       - Per D-04: if transform.scaleY < 0, flipV = true

    4. applyTransform(left, top, width, height, transform): {left, top, width, height, rotate, flipH?, flipV?}
       - Per D-01: if transform.rotateCX !== undefined && transform.rotateCY !== undefined:
         - Calculate bounding box from (left, top) to (left+width, top+height)
         - Rotate both corners around (rotateCX, rotateCY)
         - Set left/top/width/height to rotated bounding box
         - Set rotate = 0
       - Else (D-02): rotate = getRotateDeg(transform)
       - Set flipH/flipV from getFlipFromScale(transform)
       - Return {left, top, width, height, rotate, ...flip}

    Import TransformResult from ../types/ast.
  </action>
